==================================================
        دليل تشغيل بوت التذاكر والدعم الفني
==================================================

1. متطلبات التشغيل:
   - تأكد من تثبيت بايثون (Python 3.8 أو أحدث).
   - قم بتثبيت المكتبات المطلوبة عبر سطر الأوامر (CMD / Terminal):
     pip install -U discord.py python-dotenv

2. ضبط الإعدادات:
   أ. افتح ملف (.env):
      - استبدل (ضع_توكن_البوت_هنا) بتوكن البوت الخاص بك من موقع Discord Developer Portal.

   ب. افتح ملف (config.json):
      - STAFF_ROLE_ID: ضع آيدي الرتبة الخاصة بفريق الدعم/الإدارة.
      - CATEGORY_ID: ضع آيدي القسم (Category) الذي ستفتح تحته الرومات (أو اتركه null).
      - PANEL_CHANNEL_ID: ضع آيدي الروم الذي تريد ظهور لوحة فتح التذاكر فيه.
      - يمكنك تخصيص نصوص الرسالة وزر الفتح كما ترغب.

3. تفعيل صلاحيات البوت (Discord Developer Portal):
   - ادخل إلى تطبيقك في بوابة المطورين -> قسم Bot.
   - قم بتفعيل خيار:
     [✓] Server Members Intent
     [✓] Message Content Intent

4. تشغيل البوت:
   - افتح موجه الأوامر داخل مجلد البوت واكتب:
     python main.py

5. إرسال لوحة التذاكر إلى السيرفر:
   - بعد أن يصبح البوت متصلاً (Online)، اكتب الأمر التالي في سيرفرك (يجب أن تمتلك صلاحية Administrator):
     !setup_tickets

مبروك! سيعمل نظام التذاكر بالكامل بشكل تلقائي.
==================================================
